## 1. Best-Effort Source Scanner

The Linux and macOS scanner walks a directory through pinned file descriptors and streams entries into a caller-supplied manifest spool. It uses no-follow, nonblocking opens, compares each opened entry with its parent-relative observation, hashes regular files in 64 KiB blocks, and rechecks file and directory identity, size, modification time, and change time. It checks the root path again after traversal. Directory names use lossless Unix bytes. Metadata is currently empty, and symbolic links and special files are rejected.

The caller supplies finite depth, descriptor, entry, per-file, and total-byte limits. Cancellation and monotonic deadlines are checked between operations and reads. The scanner consumes its spool and returns it only on success; after an error the caller must discard the partial spool and must not publish it. The caller supplies a private spool outside the selected source and owns its cleanup. A successful returned spool can include entries the caller added previously and must be finalized separately.

This is a best-effort live read, not a snapshot or evidence that content remains immutable after it was checked. Metadata comparisons cannot detect every concurrent mutation. Some filesystems may block individual filesystem operations despite nonblocking flags, so deadline checks cannot guarantee a hard syscall deadline. The scanner does not enforce a filesystem boundary, preserve links or metadata, allocate resource-pool permits, provide staging, or implement capture publication. The caller must reserve scanner resources and supply policy, capability, and authorization checks before use. Windows and other unsupported targets return an explicit unsupported error.

The initial root path must already be resolved and authorized by the caller; no-follow flags protect its last component and subsequent descriptor-relative descent. A raced replacement can be detected after an entry is opened, but these portable flags do not prevent a device node from being opened before its type is checked. An untrusted mutable source requires additional access isolation before this scanner can be admitted. This component is unavailable to enabled jobs until those preflight and isolation requirements are implemented.
